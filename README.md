# ELy's Valentine's Day 💕

A special Valentine's Day webpage created with love for Ely!

## Features

- 💖 Beautiful animated Valentine's Day card
- 🎨 Gradient background with floating hearts
- ❤️ Interactive heart that creates more hearts when clicked
- 🎁 Hidden surprise message (click the button to reveal!)
- 📱 Responsive design that works on all devices

## How to View

Simply open `index.html` in your web browser to see the Valentine's Day message!

## Technologies Used

- HTML5
- CSS3 (with animations and transitions)
- Vanilla JavaScript
